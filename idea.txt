Topic: Bureaucracy
Idea: Office Clerk Simulator

Classes:
- Documents
    This is an abstract class that will contain an innit method with document data(who submitted it, what the document is about, 
    its status, notes, and who signed it). It will also have method verification, to verify documents and change its status.
- Complaint
    This class inherits methods from the Document class. Verification will check whether the complainant is specified, if yes, status will change to approved.
    If not, the complaint will fail verification and status will be changed to rejected.
- Application
    This class inherits methods from the Document class. Verification will check whether any attachments are attached to the document.
    If not, the document will fail verification, and status will be changed to revision. If yes, to approved.
- Permit
    This class inherits methods from the Document class. Verification will check if fee was paid and the level of danger
    (like request for building, work with chemicals, store tnt). If fee is not paid status will be changed to revision. 
    If level of danger is high permit request will be rejected. If low/medium it will be approved. 
- Information
    This class inherits methods from the Document class. Verification will check if documents that were requested are secret documents.
    Status will change to approved if documents are nor secret. If documents are secret, but person that made request has right to see them status will 
    change to approved, if not, then status will be rejected.
- License
    This class inherits methods from the Document class. Verification will check if bussiness type is approved by the city and if bussiness will be 
    opened in correct area(like chemical phactory in residental zone). If both are correct then status will change to approved. 
    If area is not correct then it will be rejected. If bussiness type not in the approved list then status will be revision.
